* PowerShell
Windows PowerShell 5.1 with PSReadLine 2.0.0 in its default (Windows) key mode.

** Survival
//byClaude [2026-11-01 Sun]
If you only remember one key: =Ctrl+C= stops whatever is running. To see
every key: =Ctrl+Alt+?= (or =Get-PSReadLineKeyHandler=).

| Stuck?                                  | Key / command                       |
|-----------------------------------------+-------------------------------------|
| Stop the running command                | =Ctrl+C=                            |
| Clear the line I'm typing               | =Esc=                               |
| Clear the screen                        | =Ctrl+L= or =cls=                   |
| List all keys                           | =Ctrl+Alt+?=                        |
| Help for a command, with examples       | =Get-Help Get-ChildItem -Examples=  |
| Find a command by part of its name      | =Get-Command *item*=                |
| What is this alias?                     | =Get-Alias ls=                      |
| Reload my profile after editing it      | =. $PROFILE=                        |
| Close the shell                         | =exit=                              |

** History
//byClaude [2026-11-01 Sun]
History is saved across sessions, so =Ctrl+R= also finds old commands.

| Action                              | Key / command                    |
|-------------------------------------+----------------------------------|
| Previous / next command             | =Up= / =Down=                    |
| Search history (type part of it)    | =Ctrl+R= (again for older), =Ctrl+S= newer |
| Commands starting with what I typed | =F8= / =Shift+F8=                |
| List this session's history         | =h= (=Get-History=)              |
| Run entry N again                   | =r N= (=Invoke-History=)         |

** Moving around
//byClaude [2026-11-01 Sun]
| Action                              | Command                          |
|-------------------------------------+----------------------------------|
| Where am I                          | =pwd=                            |
| Go to a bookmark / list bookmarks   | =j name= / =j=                   |
| Edit the bookmark list              | =j marks=                        |
| Back to where I was before =j=      | =popd=                           |
| Remember folder and go / go back    | =pushd path= / =popd=            |
| Open this folder in Explorer        | =ii .= (=Invoke-Item=)           |
| Open a file in nvim                 | =v file= (my alias)              |
| Edit my profile                     | =j ps=, or =v $PROFILE=          |
=cd -= (go back) only exists in PowerShell 7, not 5.1. Use =popd= instead.

** Buffers and tabs
//byClaude [2026-11-01 Sun]
A buffer is a file in memory, a window is a view of a buffer, a tab is a
layout of windows. Closing a window doesn't close the file.

| Action                        | Key / command                         |
|-------------------------------+---------------------------------------|
| Switch buffer                 | =SPC f b= (picker), =:b name=         |
| Last file / previous file     | =C-^=                                 |
| Next / previous buffer        | =:bn= / =:bp=                         |
| Close buffer (keep layout)    | =:bd=                                 |
| New tab                       | =:tabnew= (or =:tabnew file=)         |
| Next / previous / tab N       | =gt= / =gT= / =N gt=                  |
| Close tab / keep only this    | =:tabclose= / =:tabonly=              |

* Doom Emacs windows
** Survival
//byClaude [2026-11-01 Sun]
If you only remember one key: =C-g= cancels whatever is going on. For window
commands, press =SPC w= and wait: which-key lists them all.

| Stuck?                                | Key                                   |
|---------------------------------------+---------------------------------------|
| Cancel anything (prompt, command)     | =C-g= (press several times if needed) |
| Back to normal state, close popups    | =Esc=                                 |
| Undo the last layout change           | =SPC w u= (winner-undo), =SPC w C-r= redo |
| See all window keys                   | =SPC w=, then wait                    |
| Too many windows: keep only this one  | =SPC w C-o= (=delete-other-windows=)  |
| Windows squashed / uneven             | ~SPC w =~                             |
| Run any command by name               | =SPC := or =M-x=                      |
| What does this key do?                | =SPC h k=, then press the key         |
| Close this window                     | =SPC w q= (=:q=) or =SPC w c=         |
| Quit Doom / quit without saving       | =SPC q q= / =SPC q Q=                 |

=SPC w= is the same map as evil's =C-w=, so the nvim keys work too: =C-w v=,
=C-w h= and so on. In insert state =C-w= deletes a word instead.

* VS Code
//byClaude [2026-11-03 Tue]
VS Code 1.143 with default keys, plus vscode-neovim (so the Neovim =C-w= keys
work in normal mode) and the Claude Code extension in the panel.

** Survival
//byClaude [2026-11-03 Tue]
If you only remember one key: =Ctrl+Shift+P= (or =F1=) runs any command by
name, and shows its key if it has one.

| Stuck?                                | Key                                   |
|---------------------------------------+---------------------------------------|
| Find any command                      | =Ctrl+Shift+P= or =F1=                |
| Open a file by name                   | =Ctrl+P=                              |
| Back to normal mode (vscode-neovim)   | =Esc=                                 |
| Side bar gone / in the way            | =Ctrl+B=                              |
| Panel (terminal, problems) gone / in the way | =Ctrl+J=                       |
| Too many splits: keep only one group  | =C-w o= (joins all groups)            |
| Closed a tab by mistake               | =Ctrl+Shift+T=                        |
| Lost in Zen mode / full screen        | =Esc Esc= / =F11=                     |
| Text too big / small                  | palette: "View: Reset Zoom"           |
| Search all keys                       | =Ctrl+K Ctrl+S=                       |
| Settings (UI / JSON)                  | =Ctrl+,= / palette: "Open User Settings (JSON)" |

With vscode-neovim, =Ctrl+W= in an editor is nvim's =C-w= prefix, not "close
tab". Close with =C-w q= or =Ctrl+F4=.
